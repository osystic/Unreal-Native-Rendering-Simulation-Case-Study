# ADR 0001: Independent sanitized history

- Status: Accepted
- Date: 2026-10-20

## Context

The completed client implementation is proprietary and cannot be copied or mirrored into OSYSTIC portfolio repositories.

## Decision

Maintain this public repository as an independently authored documentation-only case study. Do not import Git history, source, assets, screenshots, evidence captures or task identifiers from the confidential project.

## Consequences

The public artifact remains safe to share, but it cannot reproduce the confidential implementation. Claims must remain capability-level and evidence-backed.
