# Public Showcase Runbook

Before changing this repository:

1. Open an issue describing the intended public claim or artifact.
2. Confirm the change can be supported by the private evidence record.
3. Do not copy from the client repository.
4. Re-run the public-safety workflow.
5. Review the disclosure boundary.
6. Obtain founder approval for any new claim, metric, screenshot, identity, demo, or publication channel.
7. Merge through a pull request only after checks pass.

If confidentiality is uncertain, leave the information out.
