# Disclosure Boundary

## Safe for this public repository

- generic capability descriptions;
- sanitized architecture;
- public technology names;
- generalized validation methodology;
- evidence-backed statements that two workstreams were completed.

## Not safe for this public repository

- client/company identity;
- client repository or PR URLs;
- task identifiers or internal naming;
- source code, headers, shaders or build artifacts;
- screenshots, videos or raw evidence from the client project;
- session logs;
- exact proprietary acceptance thresholds;
- commercial terms or private conversations.

Any future addition must be reviewed against this boundary before merge.
